# Journal and Postmortem

Record decisions, including rejected trades.

## Event fields

- Timestamp in Eastern Time
- Session ID
- State
- Event type
- Symbol
- Thesis
- Evidence and timestamps
- Candidate score
- Proposed and actual risk
- Intended order
- Reviewed order
- Submitted order
- Fill
- Position and buying-power changes
- Decision
- Reason
- Rule checks
- Errors or uncertainties

## End-of-session review

Report:

- Starting and ending value.
- Realized and unrealized P/L.
- Maximum drawdown.
- Trades and rejected proposals.
- Win rate only when sample size is stated.
- Average modeled risk and realized outcome.
- Slippage and reconciliation discrepancies.
- Rule violations.
- Process lessons.

Do not change the strategy after one result. Separate process quality from outcome.
